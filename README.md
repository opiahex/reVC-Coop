Кооперативный мультиплеер для **GTA Vice City**, встроенный в движок reVC. Напарник подключается к общему миру и играет своим Томми.

## Игроки

Бег, прыжки, смена оружия, стрельба и эффекты выстрелов. Над напарником видны ник, здоровье, броня, иконка оружия и звёзды его розыска. У каждого игрока свой розыск; NPC реагируют на прицеливание, выстрелы и попадания обоих игроков. Смерть и арест одного игрока не сбрасывают мир напарника.

![Напарник в общем мире — вид от хоста](assets/players.png)

## Транспорт и мир

Можно ехать за рулём или пассажиром. Передаются движение машин, вращение колёс и повреждения; в общей сессии есть трафик и прохожие. Полицейские вертолёты создаются общей сессией. Уличные оружие, боеприпасы, деньги, здоровье и броня подбираются один раз и исчезают у всех участников.

## Чат и интерфейс

Русский ввод, сообщения над головой, метки напарника на радаре. Внешний вид чата фиксирован; размер текста и число строк меняются командами `/fontsize` и `/pagesize`.

## Запуск

1. Соберите проект по [инструкции](docs/BUILDING.md). Нужны собственные файлы обычной GTA Vice City; Definitive Edition не подходит.
2. Скопируйте `reVC.exe` и содержимое `gamefiles/` в отдельную тестовую копию игры. Запускайте `reVC.exe`.
3. Создайте рядом с ним `vc-coop.ini`:

```ini
[native]
sandbox=1
name=Host
host=1
auto_connect=1
address=127.0.0.1
port=7781
fps_limit=60
```

У напарника: `name=Guest`, `host=0`, `address=` IP хоста. Для двух копий на одном ПК оставьте `127.0.0.1`; для подключения по сети нужен доступ к UDP-порту `7781`.

`sandbox=1` включает тестовую свободную игру без сюжетных скриптов. Меню подключения открывается по **F8**.

## Управление

| Клавиша | Действие |
| :--- | :--- |
| **F8** | Меню подключения |
| **T** / **Enter** | Открыть чат |
| **Enter** / **Esc** | Отправить / закрыть чат |
| **G** | Занять свободное пассажирское место рядом |
| **Tab** | Список игроков |
| **F7** | Показать / скрыть чат |
| **PgUp** / **PgDn** | История чата |

## Текущее состояние

Это ранняя сборка для свободной игры. Синхронизация ещё дорабатывается, особенно столкновения и работа при задержках сети. Сюжет, катсцены и сохранение общего прогресса пока не перенесены.

В сетевой игре по умолчанию **60 FPS**. В `vc-coop.ini` можно задать любой положительный `fps_limit`; `0` отключает ограничение. Изменение применяется после перезапуска. Симуляция коопа работает с исходным шагом 30 Гц независимо от частоты отрисовки. Повышайте FPS на свой страх и риск: совместимость всех эффектов и игровых сценариев при высоких значениях ещё не проверена.

Обычные ASI/CLEO-плагины с этой сборкой не работают: кооп скомпилирован непосредственно в `reVC.exe`.
